# Student Marks Analysis Using Python

## Overview
A beginner-friendly Python project that analyzes student marks and summarizes academic performance using basic statistical calculations and data visualization.

## Objectives
- Calculate total marks and average marks.
- Find the highest and lowest marks.
- Display individual student results.
- Categorize student performance.
- Visualize marks using a bar chart.
- Export results to a CSV file.

## Technologies Used
- Python
- Google Colab / Jupyter Notebook
- Pandas
- Matplotlib

## Dataset
The project uses a sample dataset containing five students and their marks out of 100.

## Methodology
1. Store student names and marks in Python lists.
2. Validate the data.
3. Calculate total, average, maximum, minimum, and range.
4. Categorize individual performance.
5. Create a results table and bar chart.
6. Export the results to CSV.

## Results
- Number of students: 5
- Total marks: 436
- Average marks: 87.20
- Highest marks: 95
- Lowest marks: 76

## How to Run
1. Open the notebook in Google Colab.
2. Run each code cell from top to bottom.
3. Review the calculations and chart.
4. Download the generated CSV file if required.

## Project Files
- `Student_Marks_Analysis.ipynb` — Complete notebook
- `student_marks_results.csv` — Analysis results (optional)
- `README.md` — Project documentation

## Conclusion
This project demonstrates Python lists, loops, functions, validation, statistical calculations, data tables, and visualization.

The dataset contains sample marks for demonstration purposes.
